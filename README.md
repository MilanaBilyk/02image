# ФотоФормат
Создатель / владелец: **Bilyk Milana**. © 2026 Bilyk Milana. Все права защищены.

бесплатный конвертер и компрессор изображений. Поддерживаются JPG, PNG, WebP, изменение размера и пакетная обработка со скачиванием ZIP.

## Публикация на Cloudflare Pages
Framework preset: **None**. Build command: **оставить пустым**. Build output directory: **/** (корень).
Это обычный статический сайт, сборка не нужна.

## Контакты и адрес
Контактный email (milana.com040404@gmail.com) уже указан в contacts.html, privacy.html и terms.html. Заполнять ничего не нужно.
Рекомендуемое имя проекта в Cloudflare Pages: **fotoformat** (адрес https://fotoformat.pages.dev). robots.txt и sitemap.xml уже настроены под этот адрес. Если имя занято и Cloudflare выдал другое, замените адрес в этих двух файлах.
Юридические тексты — шаблоны, перед коммерческим запуском покажите их юристу.

## Монетизация (пока не подключена)
- Реклама: на главной есть пустой блок `<div class="slot">`. Вставьте туда код рекламной сети (после одобрения сети) и обновите политику конфиденциальности.
- Платные функции: потребуется платёжный сервис и серверная часть (Cloudflare Workers) для проверки оплаты.

## Ограничения
Обработка идёт в браузере. Формат HEIC большинство браузеров не открывает, поэтому он не поддерживается. WebP-экспорт не работает в части старых браузеров (сайт покажет сообщение). Лимит: 30 МБ на файл. Метаданные (EXIF) удаляются при конвертации.
